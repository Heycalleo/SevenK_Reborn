ATURAN KEAMANAN FIRESTORE (Firestore Security Rules)
=====================================================

Salin isi di bawah ke: Firebase Console > Firestore Database > tab "Rules",
lalu klik "Publish".

Aturan ini membuat:
- Semua orang boleh MEMBACA komentar.
- Semua orang boleh MENULIS komentar baru (tidak perlu login).
- Komentar tidak bisa diubah atau dihapus lewat website.
  Untuk menghapus komentar yang tidak pantas, buka Firebase Console >
  Firestore Database > koleksi "comments", lalu hapus dokumen yang dimaksud.

--------------------------------------------------------------------------
rules_version = '2';

service cloud.firestore {
  match /databases/{database}/documents {
    match /comments/{commentId} {
      allow read: if true;

      allow create: if request.resource.data.name is string
        && request.resource.data.name.size() > 0
        && request.resource.data.name.size() <= 40
        && request.resource.data.message is string
        && request.resource.data.message.size() > 0
        && request.resource.data.message.size() <= 500
        && request.resource.data.createdAt == request.time;

      allow update, delete: if false;
    }
  }
}
--------------------------------------------------------------------------

Catatan:
- Anti-spam dilakukan di sisi klien (comments.js): honeypot, tantangan ketik
  kata, cooldown 60 detik antar kirim, dan sensor kata kasar.
- Untuk lapisan keamanan ekstra, aktifkan App Check (reCAPTCHA) di
  Project Settings > App Check. Ini menolak permintaan dari bot yang
  tidak lolih tantikan.
